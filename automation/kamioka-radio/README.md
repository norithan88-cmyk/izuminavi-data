# 神岡ラジオの置き場所

神岡ナビ（hida-kamioka）のラジオは、APIキーをこのリポジトリと共用するため、ここで毎朝作っています。

- 作り方・台本のルール・神岡ネタ帳・お便りは hida-kamioka の `automation/radio/` にあります（そちらを編集すれば反映されます）。
- ここには出来上がった `daily.mp3`・`daily-script.txt`・`daily-sources.json`・`broadcast-history.json` だけが保存されます。
- 実行：`.github/workflows/kamioka-radio.yml`（毎朝6時40分ごろ・手動実行も可）。
