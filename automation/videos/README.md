# みおんの歴史動画 一覧

TOPページ「みおんの歴史動画」欄のプルダウンが読みに行くデータ。
新しい動画ができたら、`videos`配列に1件追加してコミット・プッシュするだけで、
WordPress側の貼り替え作業なしにサイトへ反映される。

各項目の意味:

- `key`: 内部管理用の短い識別子（重複しなければ何でもよい）
- `id`: YouTube動画のID（URLの`v=`の後ろの部分）
- `title`: 埋め込みプレイヤーのタイトル・再生ボタンのaria-labelに使う
- `desc`: プルダウンで選んだ時に表示される説明文

サイト側はこのJSONの取得に失敗した場合、HTMLに直接書かれた既定の動画
（石川丈山編）をそのまま表示する（フォールバック設計）。
